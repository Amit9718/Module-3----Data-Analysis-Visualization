# Module 3 — Data Analysis & Visualization

## Overview
Exploratory Data Analysis on the Titanic dataset using NumPy, Pandas, and Matplotlib.

## How to Run
Open `notebook.ipynb` in Google Colab or Jupyter Notebook.

```bash
# Local Jupyter
pip install numpy pandas matplotlib seaborn jupyter
jupyter notebook notebook.ipynb
```

## Key Techniques
- Data loading and inspection
- Handling missing values and duplicates
- Aggregations and group-by analysis
- Bar, line, and pie chart visualizations
- Correlation analysis

## Dataset
Titanic — built into seaborn (`sns.load_dataset('titanic')`)
